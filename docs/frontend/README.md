# 前端文档

当前实施依据：[sprobe_v1_2.md](sprobe_v1_2.md)。

## 范围

- Console UI：公开总览、认证详情、历史趋势、空态与异常态。
- 部署形态：Cloudflare Pages 静态站点；可选 Pages Functions + D1 接收与只读 API。
- 数据边界：D1 只保存 latest + 1 分钟聚合，不保存完整历史快照。
- 公开视图与认证视图分离；公开详情默认关闭。

## 阅读顺序

1. 第 1–2 章：定位、访问模式、术语与角色。
2. 第 3–5 章：技术栈、目录、模块职责、页面和组件。
3. 第 6–7 章：只读 API、错误契约、缓存、D1 模型与幂等。
4. 第 8–10 章：状态、单位、异常、部署、安全和额度。
5. 第 11–14 章：测试验收、计划依赖、FAQ、变更记录。

## 工程约定

- 目录结构与 3.2 一致；技术栈尚未冻结（React 18+ 或 Vue 3），`console/` 当前只保留骨架。
- 所有字段路径以契约 v1.0 和后端文档 6.2 为准，不在前端另造同义字段。
- 公开视图只返回白名单字段；认证响应禁止边缘缓存。
