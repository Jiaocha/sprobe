# 后端文档

当前实施依据：[rust_v1_3.md](rust_v1_3.md)。

## 范围

- Agent 单二进制：采集、规范化、快照、健康检查、推送、WAL、Prometheus。
- 覆盖 Linux（musl/gnu，x86_64/aarch64）、Windows x86_64、macOS 13+。
- 服务端只定义接收契约，不在本仓库实现长期存储和查询引擎。
- Console 是独立前端项目，见 [../frontend/sprobe_v1_2.md](../frontend/sprobe_v1_2.md)。

## 阅读顺序

1. 第 0–1 章：版本矩阵、目标、范围和非目标。
2. 第 2–3 章：模块职责、调度、采集、规范化、健康和关键流程。
3. 第 4 章 + 附录 A：指标定义、单位、边界和质量分级。
4. 第 5–8 章：跨平台、数据结构、配置部署、输出上报。
5. 第 9–12 章：安全、可靠性、日志告警、测试验收。
6. 第 13–16 章：计划、风险、FAQ、变更记录。

## 工程约定

- MSRV 1.95，工具链由仓库根目录 `rust-toolchain.toml` 锁定。
- 目录结构与 3.11.2 一致：`src/` 按配置、调度、采集、规范化、快照、健康、输出、WAL、HTTP、遥测分层。
- 当前 `src/main.rs` 只是入口占位，不包含采集或 CLI 实现。
- 任何指标或契约变更，先改文档和 `contract/`，再改实现与测试。
